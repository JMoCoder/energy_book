## 第二步：撰写规范摘要（核心原则，必须遵守）

### 写作风格
- **禁止**"定义轰炸"式开头，每节必须用具体场景/问题/数据引入（200-400字）
- 每个抽象概念**必须**配一个生活类比，用 `callout-analogy` 组件呈现
- 所有案例**优先**使用中国真实项目、政策、企业（精确到MW数/文号/年份）
- 语气：专业严谨但不枯燥，像一位懂行的朋友在讲解

### 每节固定结构（8段，缺一不可）
```
① 场景引入（200-400字）
② 学习目标（3-5条bullet）
③ 正文内容（2-4个H2子模块，核心正文内容必须达到5,000字以上）
   每个子模块 = 讲解 + 至少1个边栏组件 + 适当SVG或表格
④ 本节小结（200-300字，bullet形式）
⑤ 底部导航（bottom-nav，含上节/主页/下节）
⑥ 知识测验（5道单选题，每题含详细解析100-150字）
⑦ 相关章节（3-5个关联链接）
⑧ 页脚
```

### 总字数要求
- 每节目标：**正文核心不少于5,000字**；全节含场景引入、测验解析、小结等约5,500-6,000字
- 测验解析计入字数；SVG代码不计入字数

## 第三步：HTML文件规范

### 文件保存路径
```
chapters/level_XX/[文件名].html
```
例：`chapters/level_01/01_1_2_电流与电压.html`

### 外部资源引用路径（固定，勿改）
```html
<link rel="stylesheet" href="../../assets/css/main.css">
<script src="../../assets/js/quiz.js"></script>
```
字体引用：
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;600;700&family=Inter:wght@400;500;700&family=JetBrains+Mono&display=swap" rel="stylesheet">
```

### 六种边栏组件类名（严格使用，不得自创）
| 用途 | 类名 | 图标 |
|------|------|------|
| 关键要点/记忆技巧 | `callout callout-tips` | 💡 |
| 常见误区/安全提示 | `callout callout-warning` | ⚠️ |
| 中国真实案例 | `callout callout-case` | 🏗️ |
| 生活类比 | `callout callout-analogy` | 🔍 |
| 深入探索方向 | `callout callout-extension` | 🔭 |
| 重要定义/公式 | `key-concept` | 📌 |

### 导航元素（三处，必须内嵌）
1. **顶部固定导航栏** `.top-nav`：含主页链接、面包屑、上下节按钮
2. **底部章节导航** `.bottom-nav`：左上节/中主页/右下节，含相邻节标题
3. **返回顶端悬浮按钮** `#btnBackTop`：右下角fixed定位

> 导航中的相邻节文件名从`章节目录.md`中查找；主页路径统一写 `../../index.html`

### SVG图表规范
- 画布：`width="100%" viewBox="0 0 800 XXX"`（高度按需）
- 颜色：主线 `#1A5F96`，次线 `#4A5568`，填充 `#E8F2FF`，高亮 `#F57C00`
- 字体：`font-family="Noto Sans SC, sans-serif" font-size="14"`
- 用 `<figure class="svg-figure">` 包裹，`<figcaption>` 写图说明

### 知识测验格式
```html
<div class="quiz-question" id="q1">
  <p class="question-text"><strong>1.</strong> 题目...</p>
  <div class="quiz-options">
    <label class="quiz-option"><input type="radio" name="q1" value="A"> A. 选项</label>
    <!-- B C D同理 -->
  </div>
  <div class="quiz-answer" id="q1-answer" style="display:none">
    <p>✅ <strong>正确答案：X</strong></p>
    <p>📖 解析：100-150字详细解析...</p>
  </div>
</div>
```

## 第五步：更新导览页与自动提交推送（必须闭环执行）

HTML 文件生成并保存后，**必须**同步完成数据更新、静态离线数据同步及 Git 远端推送闭环：

**一键自动化执行方式（推荐）**：
在终端运行全自动发布脚本（将 `01_1_4` 替换为实际章节编号）：
```bash
python3 scripts/publish_chapter.py 01_1_4
```
该脚本会自动：
1. 将 `data/toc.json` 中的 `"status"` 状态修改为 `"available"`
2. 校验 HTML 文件是否存在
3. 将最新 TOC 状态同步更新至 `index.html` 中的 `_INLINE_TOC` 变量
4. 自动执行 `git add`、`git commit` 并 `git push origin main` 推送至 GitHub
